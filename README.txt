RAMSAKAL INNOVATIONS - AUTOCARE GARAGE DEMO

FILES
- index.html: website structure and content
- style.css: responsive visual design
- script.js: mobile navigation and WhatsApp enquiry form

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in VS Code or STS (as a general folder).
3. Double-click index.html to preview in a browser.
4. For local development, use a simple local server or VS Code Live Server.

BEFORE SHOWING TO A REAL CLIENT
1. Replace AUTOCARE GARAGE with the business's real name.
2. In script.js, replace WHATSAPP_NUMBER with the owner's WhatsApp number in international format, digits only.
3. Replace phone, email, address, working hours and service details in index.html.
4. Replace sample package prices with owner-approved prices.
5. Replace stock photos with photos the business owns or has permission to use.
6. Add the real Google Maps embed for the verified workshop location.
7. Replace all placeholder claims with truthful business information.

IMPORTANT
- This is a static frontend demo.
- The enquiry form opens WhatsApp with a prefilled message. It does not save bookings to a database.
- No Spring Boot backend or MySQL is connected.
- Google Fonts and Unsplash images need an internet connection.
- Do not publish sample prices or placeholder contact details as if they are real.
